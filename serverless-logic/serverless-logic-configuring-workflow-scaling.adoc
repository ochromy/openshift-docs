You can configure scaling for your {ServerlessLogicProductName} workflows to handle varying workloads efficiently. This section describes how to scale workflows manually and configure horizontal pod autoscaling (HPA) for automatic scaling based on resource utilization metrics.

Proper scaling configuration ensures your workflows can handle increased load while optimizing resource usage in your {product-title} cluster.
